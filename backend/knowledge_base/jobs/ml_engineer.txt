Job Title: Machine Learning Engineer

Description:
A Machine Learning Engineer develops, trains, evaluates, and deploys machine learning models and systems. The role focuses on building reliable machine learning solutions and integrating models into real-world applications.

Role Responsibilities:

* Collect and preprocess data for machine learning.
* Clean and transform datasets.
* Perform feature engineering.
* Select appropriate machine learning algorithms.
* Train machine learning models.
* Evaluate model performance.
* Tune and improve machine learning models.
* Compare different machine learning algorithms.
* Deploy machine learning models.
* Monitor deployed models.
* Maintain and improve machine learning systems.
* Work with software engineers and data scientists.
